# 数据集采集步骤

1. 运行 `get_dataset.py`：得到 npz 文件以及 mask 文件。需要注意的是

    ```python
    gray_mask = np.all(array_seg == [0, 0, 0], axis=-1)
    ```

    此步骤的目的在于将语义分割后的图像转换为二值化图像为了方便转为掩码（其他地图自带车辆会影响标签的计算）。直接在右侧`世界大纲视图`中将所有的静态车辆删除即可
2. 语义分割标签为

    | 类别   | 颜色           |
    | ------ | -------------- |
    | 行人   | (220, 20, 60)  |
    | 路标   | (157, 234, 50) |
    | 道路   | (128, 64, 128) |
    | 车辆   | (0, 0, 142)    |
    | 交通灯 | (250, 170, 30) |
    | 未知   | (0, 0, 0)      |

3. 运行 `mask2label.py`：获得目标检测标签，用于计算损失
4. 运行 `split_dataset.py`：分割训练集和验证集
5. 运行 `vis_label.py` 查看目标检测标签可视化效果
6. 测试数据集是否正确采集 `nmr_test.py`
